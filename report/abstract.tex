\section*{Abstract}
This report contains the details of Cultural HK, a full-stack web application
for Hong Kong cultural locations and events. The system is built with
React using Tailwind CSS and Shadcn UI components \cite{shadcn_ui}, with a Node.js express
backend using MongoDB database. Besides the basic requirements, we spent
a lot of effort on UI design and extra features, including UX improvements, 
security, home page and event like buttons.
